செய்யுள் / பழமொழி

Section A2: five lines from the syllabus list, each with one word missing, 10 marks. Students know the line but lose marks on a look-alike word, like திருத்தி for திருந்த. This lab trains the exact word, using the real options from five 2026 prelim and practice papers.

Say each line from its meaning, then tap it to check.

How this trains the brain

  • Meaning first. Every line comes with what it means. A line you understand is stored with more hooks than a string of sounds.
  • A different gap each time. The missing word moves around the line, so recall does not depend on one cue.
  • Build the line. Putting the words in order forces exact recall of every word, which is the skill A2 marks.
  • Spacing and a confidence check. Missed lines return soon. A lucky guess does not count as word-perfect.
