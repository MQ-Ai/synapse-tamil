How the drill trains the brain

  • Retrieval, not rereading. You pull the word out of memory before you see the answer, which strengthens recall more than reviewing a list.
  • Contrast pairs. Both twins appear side by side with the changed letter highlighted, so the brain stores the difference instead of blurring the two.
  • Spacing. A missed word returns three cards later, and words you know well come back less often.
  • Confidence check. A lucky guess is not counted as mastered. This keeps false confidence out of the exam hall.

How this trains the brain

  • Meaning first. Every line comes with what it means. A line you understand is stored with more hooks than a string of sounds.
  • A different gap each time. The missing word moves around the line, so recall does not depend on one cue.
  • Build the line. Putting the words in order forces exact recall of every word, which is the skill A2 marks.

How this trains the brain

  • Both directions. Word → meaning builds reading; meaning → word builds the recall you need when writing.
  • Look-alike choices. Wrong options are real meanings from the same list, so you must know the word, not guess from shape.
  • Spacing and a confidence check. Missed words return three cards later. A lucky guess is not counted as mastered.
